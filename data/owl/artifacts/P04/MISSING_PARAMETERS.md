# MISSING_PARAMETERS — inferences (each tagged inferred in FROZEN_CONFIG)

1. Train/val/test split ratio + seed + stratification. Paper: only "same split as AMC-Net/AWN" (no ratio/seed; repo offline). Chose stratified-by-(mod,SNR) random split 60% train / 20% val / 20% test, seed 0 (132k/44k/44k). Stratification preserves 1000-per-(mod,SNR) balance in each split. Expected impact: MEDIUM — different ratios shift overall accuracy by ~1–2pp; stratification avoids SNR-leakage bias. Split SHA recorded in RESULTS.json.
2. FFT/IFFT convention. Paper: FFT→gate→IFFT (Eq.2–3), no norm specified. Chose torch.fft.fft / ifft (unnormalized forward), real part taken after IFFT, residual add. Expected impact: LOW (scale absorbed by MLP gating + BN).
3. FDDM MLP activations + complex handling. Paper: "single hidden layer with 32 neurons", shared MLP; no activation, no complex treatment. Chose: input = magnitude spectrum |FFT| (length 128, real); MLP = Linear(128→32)→ReLU→Linear(32→128)→Sigmoid (gate in [0,1]); gate multiplies complex spectrum elementwise. Shared across I/Q. Expected impact: MEDIUM — sigmoid gating is the natural "reweight/denoise" reading; alternatives (no sigmoid) risk instability.
4. CNN padding. Paper text gives kernels only; Fig.1 labels padding=(1,0) which cannot preserve L with kernel (1,3). Chose padding=(0,1) for all four convs (pad width by 1, height 0): layer2 kernel height 2 reduces height 2→1, length preserved 128. Gives stated x_cnn ∈ R^{256×L}. Expected impact: LOW (only padding that matches stated shapes).
5. CNN activation/BN order. Paper inconsistent: body+Fig say ReLU, Eq.4 says Elu and BatchNorm(Elu(Conv)). Chose Conv→BN→ReLU (standard, stable). Expected impact: LOW.
6. Transformer FFN width/activation, norms, W^O. Paper: "feed-forward network", residuals + layer norms, no dims. Chose per block: LayerNorm→MHA→residual→LayerNorm→FFN(Linear(L→4L)→ReLU→Dropout→Linear(4L→L))→residual (pre-norm variant for stability); W^O ∈ R^{(h·dv)×L}. Dropout 0.5 after attention and FFN ("dropout 0.5 after each layer"). Expected impact: MEDIUM — wider FFN adds capacity; pre-norm chosen for stability at high dropout.
7. Attention over which axis. Paper: X∈R^{C×L}, W∈R^{L×dk}, QK^T → C×C map. Implemented exactly (attention over channel/feature axis, sequence length is projection dim). dk=dv=L_cur/h with h=2; second block L=64→dk=32. Expected impact: LOW (forced by Eq.5–7 dims).
8. Distillation Conv1d channels. Fig: "Conv1d (256,3,padding=1)" → chose in=256/out=256, k=3, pad=1, +ELU+BN+MaxPool1d(3,stride2,pad1): (256,128)→(256,64). Expected impact: LOW.
9. Final classifier input ("last dimension of the feature vector"). Ambiguous. Chose last time-step vector of Block2 output (B,256) → MLP Linear(256→256)→ReLU→Dropout(0.5)→Linear(256→11) + softmax via CrossEntropy.
